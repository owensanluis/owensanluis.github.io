02 / Work

Selected projects.

A collection of practical projects showcasing my experience in software development, cybersecurity, and problem-solving through technology.

Student Project

USB RegParse – Windows USB Registry Forensics Tool

A Python-based digital forensics tool for analyzing live and offline Windows Registry data to extract USB device information, connection timestamps, drive mappings, and user activity artifacts. Features multithreaded scanning, timeline reconstruction, a Tkinter GUI, and CSV export.

Python Digital Forensics Windows Registry
Student Project

Custom File Scanner – YARA & File Signature Analysis

Collaborated on Python-based forensic scanners that use YARA signatures, file header analysis, and SHA-256 hashing to identify target files within mounted Windows disk images. Evaluated implementations against disk images containing over 88,000 files, successfully identifying all 220 target files.

Python Digital Forensics YARA
Student Project

Visual Network Traffic Analyzer

A Python-based network monitoring tool developed using Scapy and PyQt5 to capture real-time network traffic, track active devices, and visualize bandwidth usage and protocol distributions. Validated packet counts and protocol statistics against Wireshark.

Python Network Security Network Monitoring
Student Project

Concurrent Syslog Analytics Server (Mini-Splunk)

Developed a multithreaded Python-based log analytics server that processes and indexes incoming logs through a custom TCP client-server protocol. Implemented mutex-protected shared state and inverted indexes to support concurrent log ingestion and efficient querying.

Python Log Analysis Concurrent Programming
03 / Research

Research work.

Academic research exploring cybersecurity challenges, detection techniques, and practical approaches to improving system security.

Undergraduate Thesis

Obfuscation-Aware Feature Engineering for Evasion-Heavy Phishing URL Detection

Investigating how obfuscation-aware URL features can improve the detection of evasion-heavy phishing URLs through static analysis and machine learning in Python. The study explores feature engineering techniques and evaluates multiple classification models such as Random Forest and XGBoost.

Cybersecurity Machine Learning Phishing Detection Feature Engineering
Research Paper

F-Max and I-Max: Distributed Feature and Training-Instance Optimization for Phishing URL Detection

Developed two complementary distributed systems for optimizing phishing URL classification by evaluating feature subsets and training-data sizes. The study uses a Pyro5-based master-worker architecture and Random Forest classification to identify more efficient dataset configurations while retaining predictive performance.

Distributed Systems Machine Learning Phishing Detection
